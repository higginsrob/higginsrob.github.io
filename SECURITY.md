# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in this portfolio website, please report it responsibly:

1. **Do NOT** create a public GitHub issue for security vulnerabilities
2. Send an email to [your-email@example.com] with:
   - Description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Suggested fix (if any)

## Security Measures

This portfolio website implements the following security measures:

### Dependency Security
- Automated dependency vulnerability scanning via CodeQL
- Regular dependency updates and security audits
- Dependency review for all pull requests

### Code Security
- CodeQL security analysis on all commits
- ESLint security rules enforcement
- TypeScript for type safety

### Deployment Security
- GitHub Actions for secure CI/CD
- Automated security checks before deployment
- No sensitive data in repository

## Response Timeline

- **Initial Response**: Within 48 hours
- **Status Update**: Within 1 week
- **Fix Timeline**: Varies based on severity and complexity

## Security Updates

Security updates will be applied as follows:
- **Critical**: Immediate patch and deployment
- **High**: Within 24 hours
- **Medium**: Within 1 week
- **Low**: Next scheduled update cycle

Thank you for helping keep this project secure!
